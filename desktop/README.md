# 语境猜词 · Mac 桌面版

百词斩单词本的 macOS 桌面版（Compose Multiplatform）。直接读取仓库内百词斩本地词库
（`lookup.db` + `zpack` 音频），用「语境猜词」方式背单词：先看 **单词 + 例句** 猜意思，
再翻面看 **释义 + 例句翻译**。与 Android 版共享同一套数据格式和进度文件，可双向同步。

---

## 运行环境

- **macOS**（音频依赖系统自带的 `afplay` / `afconvert`，无需额外安装；建议 macOS ≥ 11）
- **JDK 21**（架构要与机器一致：Apple Silicon 用 arm64，Intel Mac 用 **x64**）
- 词库数据来自仓库内 `app/src/main/assets/baicizhan/`（`lookup.db`、`baicizhantopicproblem.db`、`roadmap/`、`zpack/`，约 4.4GB）

## 启动

开发运行（在仓库根目录执行）：

```bash
./gradlew :desktop:run
```

- **读取目录**（只读）：`app/src/main/assets/baicizhan/`
- **写入目录**：`mac_data/`（进度、设置等 JSON，自动创建）

打包成独立 App（可选）：

```bash
./gradlew :desktop:packageDmg     # 生成 .dmg
```

> ⚠️ `packageDmg` 用 jpackage 按**当前机器架构**打包，**不能跨架构**（arm64 打的 dmg 在 Intel Mac 打不开），且**不会**把 4.4GB 词库打进包。要在另一台 Mac 上运行，推荐下面的「迁移到另一台 Mac」直接跑源码。

## 迁移到另一台 Mac（源码运行）

把**整个仓库**（含 4.4GB `app/src/main/assets/baicizhan/`）复制过去，然后：

1. **装对应架构的 JDK 21**——Intel Mac 必须装 **x64** 版（如 [Temurin 21 / macOS / x64](https://adoptium.net/temurin/releases/?version=21&os=mac&arch=x64)）。
   - 验证：`java -version` 显示 `21.x`、64-Bit。
   - 多版本共存时指定：`export JAVA_HOME=$(/usr/libexec/java_home -v 21)`（可写进 `~/.zshrc`）。
2. **首次联网**：第一次运行会下载 Gradle 8.11.1 + 依赖（之后可离线）。
3. **在仓库根目录运行**：
   ```bash
   cd TestApplication
   chmod +x gradlew          # 复制后可能丢可执行权限，跑一次即可
   ./gradlew :desktop:run
   ```

要点：务必在**仓库根**执行（不是 `desktop/` 里），否则注入不到词库路径。

## 普通窗口

### 顶栏

| 项 | 说明 |
|----|------|
| **词书** | 中考 / 高考 / 四级 / 六级 / 雅思，记住上次选择，下次启动自动恢复 |
| **未斩 / 已斩 / 不认识** | 下拉选 3 种**互斥**列表。「不认识」= 猜词翻面看过翻译的词（独立第三类，未斩/已斩都不含它）。**只有点「斩」**才会把词从「不认识」移出并归入「已斩」；浏览（翻页）不再自动增删。进入某个列表后该列表在本次浏览中保持稳定，增删下次进入生效 |
| **过滤** | 跨词书去重：开启后排除所有更高优先级词书已包含的词（优先级：中考 > 高考 > 四级 > 六级 > 雅思） |
| **朗读** | 只读单词 / 只读例句 / 都读·先单词 / 都读·先例句 |
| **同步** | 导出 / 导入进度 JSON（与 Android 互通） |
| **透明** | 开启后，鼠标移出窗口自动淡为半透明（可透视背后内容），移回恢复不透明；默认开，可关 |
| **贴底** | 进入贴底悬浮模式（见下） |
| 计时器 | 本次学习时长 |

### 卡片

- **未翻面**：单词（大字）+ 音标 + 例句，例句中目标词高亮（含常见词形变化）
- **翻面后**：单词作 50% 透明水印铺底，叠加 音标 + 例句 + 中文释义 + 英文释义 + 例句翻译
- 点击卡片任意处 = 翻面 / 收起

### 底部 / 悬浮

- 底部 **上一个 / 下一个** 按钮
- 左下角 **可拖动**的「斩 / 已斩」按钮：标记单词掌握状态（覆盖词库默认值，本地持久化）

### 键盘快捷键

| 键 | 功能 |
|----|------|
| `←` / `→` | 上一个 / 下一个 |
| `↑` / `空格` | 切换显示 / 隐藏翻译（与点击卡片一致） |
| `↓` | 播放例句 |
| `P` | 播放单词 |

## 贴底模式

**启动即默认进入贴底模式**（也可从普通窗口顶栏「贴底」进入）。屏幕**底部**出现一条**半透明、不置顶**（可被其他窗口覆盖）的悬浮条，专为上班摸鱼背单词设计：

- **鼠标移入** → 显示「单词 + 音标 + 例句」一行（半透明黑底 + 低对比白字，高度随内容）
- **鼠标移开** → 全部隐藏（仅留一条几乎不可见的提示线，便于再次定位）
- **可拖动**：在条上按住拖动即可移动位置（单击 = 翻译）
- **键盘**（鼠标在可见区域内时生效）：方向键翻页、空格/↑ 翻译、↓ 读例句、P 读词、**Esc 恢复普通窗口**
- 条上仅留 **斩** 键 + **❐**（恢复普通窗口）

注意：因为不置顶，被其它窗口完全盖住时，鼠标无法移到它上面，也就无法显示/操作——这是为了不显眼的取舍。

## 进度同步（与 Android 互通）

- **导出**：顶栏「同步 → 导出进度…」→ 保存为 `vocab_progress.json`
- **导入**：顶栏「同步 → 导入进度…」→ 选择 JSON（覆盖本地斩状态）

JSON 格式与 Android 版完全一致，可在手机和 Mac 之间互相导入。

## 本地数据

所有设置与进度存在 `mac_data/prefs.json`：

- 词书选择、过滤视图
- 浏览进度（按「词书 + 过滤视图」分别记录，互不干扰）
- 朗读模式、跨词书过滤开关
- 斩 / 未斩 override
- 「不认识」集合（查看过翻译的词，与 Android 互通）
- 例句轮播索引

删除此文件即可重置所有本地状态（不影响词库）。

## 音频说明

- 用系统 **`afplay`** 播放、**`afconvert`** 解码：MP3 / AAC 通吃（百词斩部分单词发音其实是 AAC，普通 MP3 解码器会静音）。
- 每段音频前自动拼一小段**静音**，吸收 CoreAudio 冷启动「吞头」——短单词（如 *biscuit*）开头辅音不再被吃掉。
- 翻页会**打断**当前朗读；相邻单词的音频在后台**预取**，翻页几乎即时出声。

---

## 常见问题

- **启动报找不到词库**：确认在**仓库根目录**运行，且 `app/src/main/assets/baicizhan/` 存在。
- **没有声音**：确认系统音量；`afplay` 为 macOS 自带，无需安装。
- **进度没保存**：确认 `mac_data/` 目录可写。

## 模块结构

| 模块 | 说明 |
|------|------|
| `core/` | Android 与桌面共享的纯 JVM 代码（`Word`、`WordBook`、`ZpakParser`、`ZpkMeta`） |
| `desktop/` | Compose Desktop 应用：`App`（普通窗口）、`DockedBar`（贴底条）、`GuessState`（状态与逻辑）、`DesktopRepository`（JDBC 读库 + zpk 缓存）、`DesktopAudio`（afplay 播放）、`DesktopPrefs`（JSON 持久化）、`SyncJson`（进度互通） |
